# 座席表｜授業配置管理（改修版）

学習塾の授業ごとの座席配置を作成・管理・印刷するための単純な静的Webアプリです。
ビルドツールは使用しておらず、`index.html` / `style.css` / `app.js` の3ファイルだけで動作します。

## 1. 公開手順（GitHub Pages）

1. GitHubで新しいリポジトリを作成する（例：`seat-table`）。**プライベートリポジトリを推奨**します（生徒・講師の個人情報を含むため）。
   - プライベートリポジトリでもGitHub Pagesは公開できますが、公開されたページ自体は誰でもURLを知っていれば閲覧できます。校内利用のみであれば、URLを校内関係者以外に共有しないようにしてください。
2. このフォルダの3ファイル（`index.html`, `style.css`, `app.js`）をリポジトリ直下にアップロードする。
3. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `/(root)` に設定して保存する。
4. 数分後、`https://（ユーザー名）.github.io/（リポジトリ名）/` でアクセスできるようになります。

### 今後の更新について
このURLは**固定**です。今後の改修では、同じリポジトリの該当ファイルを差し替える（コミットし直す）だけで、同じURLのまま最新版に更新されます。新しいリポジトリを作り直す必要はありません。

## 2. 旧サイト（ChatGPT Sites版）のデータを引き継ぐ

旧サイトのブラウザから書き出した `seat-table-backup.json`（または今回の新アプリの「設定・バックアップ」タブから書き出したファイル）があれば、以下の手順で読み込めます。

1. 新しいサイトを開く
2. 上部タブの「設定・バックアップ」を開く
3. 「バックアップから復元」でJSONファイルを選択する
4. 確認ダイアログで「実行する」を押す

これで生徒名簿・講師名簿・座席配置・曜日プリセットがすべて反映されます。

## 3. データの保存場所とバックアップ

- データはブラウザの `localStorage`（キー: `seat-table-v1`）に自動保存されます。端末・ブラウザ単位の保存のため、**複数の端末やブラウザで共有はされません**。
- 「設定・バックアップ」タブの「JSONをダウンロード」から、いつでも全データをファイルに書き出せます。定期的なバックアップを推奨します。
- ブラウザのキャッシュ・閲覧履歴を消去する操作を行うと、`localStorage` のデータも消える場合があります。

## 4. 今回の改修内容（旧サイトからの変更点）

- 科目を国語・数学・英語・理科・社会の5つだけでなく、算数・物理・化学・生物・地学・現代文・古文・漢文・日本史・世界史・地理・公民・情報・小論文などを含む候補リスト＋自由入力に拡張
- 生徒名簿・講師名簿に、ドラッグ＆ドロップ／上下移動ボタン／五十音順ボタンによる並び替えを追加
- 講師名簿にもExcelからの複数行貼り付けに対応（生徒名簿と同じ操作感）
- 印刷CSSを見直し、**科目を最優先で最も大きく・太く**表示（生徒名・担当講師・席番号がその次に読みやすいサイズ）。白黒印刷でも判別できるよう、色だけでなく枠線の太さ・実線／点線でも状態（講習・振替・欠席）を区別
- 狭い画面幅でも表やボタンが重ならないよう、横スクロールと折り返しに対応
- 「設定・バックアップ」タブを新設し、JSON書き出し／読み込みに対応
- 担当講師は引き続き講師名簿に登録された人だけを選択可能。集団授業は「＋集団行」ボタンからの手動追加のみで、自動生成は行いません

### あえて簡略化した点（ご確認ください）
- **「画像から取り込み」機能**：旧サイトには画像から科目・担当講師・生徒を自動認識する機能がありましたが、この新しい構成（GitHub Pagesの静的サイト）は外部サーバーやAPIキーを持たないため、自動認識をそのまま安全に組み込むことができません。今回は「画像を表示しながら手動で入力する」補助ウィンドウに変更しています。自動認識を復活させたい場合は、認識専用の小さなサーバー（バックエンド）を別途用意する必要があり、別途ご相談ください。

## 5. 動作確認のお願い

公開後、以下を一度確認していただくと安心です。

- 生徒名簿・講師名簿にExcelから数行貼り付けて反映されるか
- 座席表で担当講師・生徒を選び、ページを再読み込みしても保持されているか
- 「＋集団行」で集団授業を追加できるか
- 「先週をコピー」が正しく動作するか（前の週の同じ曜日にデータがある状態で）
- 「A3横で印刷」のプレビューで科目が大きく表示されているか
- スマホやウィンドウを狭くした状態で表が重ならないか
- 「設定・バックアップ」でJSONを書き出し、別ブラウザで読み込めるか

不具合があれば、その画面・操作内容を教えてください。
